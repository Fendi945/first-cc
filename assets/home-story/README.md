# DAY1 Home Story Assets

此目录用于新版 `dayi.homes` 首页的连续故事视觉资产。

## 目标

所有主故事画面尽量表现**同一座院子、同一人物体系、同一设计语言、连续时间线**，避免从不同项目中拼贴出“案例合集感”。

## 计划文件

- `00-prologue-desktop.webp` — 序幕桌面宽幅
- `00-prologue-mobile.webp` — 序幕手机版
- `01-longing.webp` — 向往
- `02-listening.webp` — 看见自己 / 倾听
- `03-clarifying.webp` — 一起梳理
- `04-building.webp` — 设计落地 / 施工
- `05-leaving.webp` — 设计师离场
- `06-life-begins.webp` — 生活开始
- `06-life-begins-desktop.webp` — 尾声桌面宽幅

## 视觉约束

- 东方自然主义、自然、自由、真实、低维护。
- 留白大于堆砌；植物疏朗；材料克制。
- 统一建筑、主树、水体、铺装、墙面和石材语言。
- 人物只作为生活线索，不抢空间主体。
- DAY1 设计师保持统一人物设定。
- 夜景：见光少见灯、照树不照满、保留暗部。
- 手机端优先，主故事图优先 3:4；关键首尾镜头另备桌面宽幅。

## 使用规则

素材未经确认前，不直接替换线上 `index.html`。先完成序幕、05 设计师离场、06 生活开始三个定调镜头，确认气质后再补齐中间故事。
