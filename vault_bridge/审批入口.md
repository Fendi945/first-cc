# 审批入口

## 操作

**以后双击桌面 Obsidian 图标，AI 引擎会自动启动，不用管它。**

如果想手动操作：

- [打开审批面板](http://127.0.0.1:8765/dashboard/)

---

## 符号说明

在审批面板里点按钮：

| 按钮 | 含义 |
|------|------|
| ✅ 通过 | 按AI原判断执行 |
| ❌ 拒绝 | 跳过不处理 |
| 📹 改视频 | 改做口播视频 |
| 📝 改文章 | 改做公众号文章 |
| 🔧 改工具 | 改做认知工具 |

> 引擎在后台运行，任务栏可以看到一个小窗口。
> 想关闭引擎就关掉那个小窗口。
