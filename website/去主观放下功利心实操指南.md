# 如何去主观、放下功利心？

> 综合 朱光潜「无所为而为」× 邵雍「以物观物」× 渔樵问对
> 2026-06-22 · 元演心智

---

## 总纲：同一个问题的两个回答

朱光潜和邵雍，一个美学，一个哲学，核心指向完全一样：

| | 朱光潜 | 邵雍 |
|--|--------|------|
| 要解决什么 | 实用的态度 → 美感的态度 | 以我观物 → 以物观物 |
| 核心方法 | 距离说 / 移情说 | 反观 / 因物转心 |
| 终极状态 | 无所为而为 | 无心 |
| 怎么形容 | 「人是自己心灵的主宰」 |「性公而明，情偏而暗」|

两个人说的其实是同一件事：**人本来有能力摆脱功利的绑架，只是需要一套方法。**

---

## 方法一：距离制造法（朱光潜）

朱光潜说得很清楚——**美感的关键不是「看什么」，而是「在什么距离看」。**

### 操作步骤

**第一步：把它当「倒影」看**

原文：
> 「看倒影，看过去，看旁人的境遇，看稀奇的景物，都好比站在陆地上远看海雾。」
> 「看正身，看现在，看自己的境遇，看习见的景物，都好比乘海船遇着海雾。」

实操：
- 遇到让你焦虑的事 → 问自己「如果这是发生在朋友身上的事，我是什么感受？」
- 遇到让你生气的人 → 问自己「如果十年后回头看这件事，我会怎么想？」
- 遇到让你纠结的决定 → 问自己「如果完全不计较得失，我选什么？」

本质就是**切换视角**——从「乘船者」变成「岸上观雾者」。

**第二步：「痛定思痛」**

原文：
> 「蔡琰在丢开亲生子回国时决写不出《悲愤诗》……必须痛定思痛。」
> 「艺术家在写切身的情感时，把它加以客观化，由站在主位的尝受者退为站在客位的观赏者。」

实操：
- 情绪上头时，先不处理、不决策、不表达
- 等情绪过去之后，再回头看——这时候看到的才是事情的「形象」，而不是「刺激」
- 每天写复盘就是这个原理——当天晚上回头看白天的事

**第三步：刻意制造形式感**

原文：
> 「古希腊和中国旧戏的角色往往带面具、穿高底鞋、用歌唱的声调——这些风格的目的正在于使艺术和自然之中有一种距离。」

实操：
- 工作前先点一支香、泡一杯茶——用仪式感把自己从日常状态拉开
- 在固定的时间和地点做特定的事——用时空分割制造心理距离
- 写作时用「他」代替「我」来叙述——把自己客观化

## 方法二：观物三层次（邵雍）

邵雍给出的路径更系统——从目，到心，到理，逐层提升。

### 三层次递进

```
观之以目 → 观之以心 → 观之以理
   ↓            ↓            ↓
 看形状      看情绪      看本质
   ↓            ↓            ↓
 最浅层      中间层      最深层
```

### 操作步骤

**第一层：从「观之以目」升级到「观之以心」**

**问题**：观之以目是最低层次——只看表面，容易被欲望牵着走。

**做法**：
- 看到一个东西，不先问「这有什么用」，先问「这看起来感觉如何」
- 看到一个消息，不先想「对我有利还是有害」，先想「这件事本身是什么」

**第二层：从「观之以心」升级到「观之以理」**

**问题**：观之以心还是主观的——你的情绪会影响判断。

**做法**：
- 问：「这件事的客观规律是什么？」（而不是「我的感受是什么」）
- 用渔樵问对的方法追问：找到这件事背后的**范畴关系**（利害/体用/名实/义利）

**第三层：反观——「以物观物」**

原文：
> 「所以谓之反观者，不以我观物也。不以我观物者，以物观物之谓也。」

**做法**：
- 把自己的意见放下，让事物「自己说话」
- 不是「我怎么看这朵花」，而是「这朵花在我面前是什么样子」
- 不是「这个方案对我有什么好处」，而是「这个方案本身好不好」

## 方法三：因物转心（邵雍的核心技术）

这是最精妙的一招，也是**最容易被忽略的一招**。

### 原理

邵雍发现：**靠「控制自己」去放下功利心，往往适得其反。** 越想「不要想」，越在想。

真正的路径是：**不去直接控制心，而是通过「观物」让心来跟随物。**

原文：
> 「既能以物观物，又安有我于其间哉！」

### 操作

当你发现自己沉浸在主观情绪中时：

```
1. 找一个具体的、客观的对象（一片叶子、一杯水、一束光）
2. 集中注意力，仔细观察它——它的颜色、形状、纹理、光影
3. 让它「占据」你的意识
4. 你会发现——当你的注意力完全在物上时，「我」自然就退后了
```

**这不是逃避，而是转移注意力的支点。** 通过把注意力从「我」转向「物」，心自然安静下来。

邵雍说的「观物之乐」就是这个意思——当你沉浸在对事物的纯粹观察中，会体会到一种超越功利的快乐，这种快乐自然取代了「情累」。

## 方法四：体用分析法（渔樵问对的具体工具）

当遇到一个具体问题，用「体用」框架来拆解：

### 操作

```
遇到一件事 →
① 问：这件事的「体」是什么？（本质、目的、内核）
② 问：这件事的「用」是什么？（工具、手段、表现）
③ 问：我现在纠结的是「体」还是「用」？

举例——你想学AI：
- 体：理解AI的原理和边界（这是目的本身）
- 用：做出一个赚钱的产品（这是工具）
→ 如果你今天学了一整天但没有「产出」，你觉得自己在「浪费时间」
   这是因为你把「用」当成了「体」——你忘记了学习的本质是理解，而不是立刻变现
```

功利心的本质就是**把「用」当成了「体」**——只看工具价值，忘了事物本身的价值。体用分析法帮你**把两者拆开，让体归体、用归用**。

## 方法五：命分区分法（渔樵问对的实操工具）

原文：
> 「具六物而得鱼者，人也。具六物而所以得鱼者，非人也。」

### 操作

遇到任何事，先分成两堆：

| 分 | 命 |
|----|----|
| 我能控制的 | 我不能控制的 |
| 我该做的 | 结果如何 |
| 我的努力 | 运气/大势/他人 |

**做法**：
- 把精力100%放在「分」上——备齐渔具、选好钓位、耐心等待
- 对「命」完全放手——鱼来不来是天的事
- **焦虑的来源只有一个：想控制「命」；豁达的来源只有一个：只管「分」**

原文：
> 「幸不幸，命也；当不当，分也。」

这不是宿命论，而是**精力的最优配置**——把能量花在能改变的地方，不在不能改变的地方消耗。

## 六、实操速查卡

| 场景 | 用哪一招 | 具体怎么做 |
|------|----------|-----------|
| **焦虑** | 命分区分 | 列出来：哪些我能控制？哪些不能？不管不能的 |
| **纠结** | 体用分析 | 拆开：什么是目的本身？什么是工具？ |
| **情绪上头** | 痛定思痛 | 先不动作，等情绪过去再说 |
| **主观偏执** | 以物观物 | 找个客观对象仔细观察，让物占据注意力 |
| **功利心起** | 距离制造 | 问自己：「如果这是发生在朋友身上呢？」 |
| **看不清楚** | 观物三层次 | 从目→心→理 逐层升级：形状→情绪→本质 |

---

## 七、每日训练

每天花5分钟做这件事：

```
1. 选一个日常之物（杯子、窗外的树、桌上的灯光）
2. 先看它的「形」——颜色、形状、质感（观之以目）
3. 再看它给你的「感受」——平静、温暖、好奇（观之以心）
4. 最后想它的「理」——它为什么是这样？它和周围的关系是什么？（观之以理）
5. 在这个过程中，注意「我」有没有退后
```

这就是「以物观物」的日常训练——每天5分钟，相当于给心做一次「去主观」的体操。

---

> **总结一句话：**
> 去主观不是压制自己，而是把注意力从「我」转向「物」；
> 放下功利心不是不要结果，而是分清什么是「分」、什么是「命」，
> 什么是「体」、什么是「用」。
