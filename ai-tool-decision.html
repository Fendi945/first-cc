背景 2026-06-26

📌 问题：免费模型不认识我的网站

在 CC-Switch 中配置了免费的 Agnes-2.0-Flash 模型以节省推理成本。但切换后模型对项目一无所知——不知道网站结构、设计规范、页面功能。

根因：[KNOWN] Claude Code 等 AI 编程工具依赖项目根目录的说明文件获取上下文。项目缺少 CLAUDE.md 或 AGENTS.md，任何新模型进入项目都相当于"空降"。

✅ 解决方案：创建 CLAUDE.md + AGENTS.md，覆盖项目全景、设计系统、技术栈、关键约定。

调研 决策 2026-06-26

🔧 Codex CLI + Computer Use 分析

调研了 OpenAI Codex CLI 本地部署、免费账号注册、以及 Computer Use 功能兼容性。

Codex 部署

安装：npm install -g @openai/codex（需 Node.js 22+）。本身免费开源，但需要 ChatGPT 订阅或 API Key 才能调用模型。

Computer Use 兼容性

配置方案Computer Use原因
官方 Plus 订阅（原始）✅ 完全可用Responses API 原生支持
CC-Switch + GPT 中转站⚠️ 部分可用需 v3.16.1+ 保留官方认证
CC-Switch + 非GPT 模型（Agnes/DeepSeek）❌ 不可用Chat Completions 协议无 computer_action 类型

与用户需求的匹配分析

  • 内容创作（写稿/文案/脚本）— ✅ Claude 主力，Agnes 辅助，不依赖 Codex
  • 剪映 — ❌ AI 无法操作桌面软件鼠标拖拽时间线
  • SketchUp / CAD — ❌ AI 无法进行 3D 建模精细操作
  • 插画 — ❌ AI 生图可作灵感参考，精细绘制靠自己
✅ 结论：当前无需开通 ChatGPT Plus（$20/月），现有方案已覆盖核心需求。专业软件靠自身技能，AI 帮不上忙。
