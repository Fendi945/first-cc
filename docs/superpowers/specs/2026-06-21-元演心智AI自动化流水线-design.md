# 元演心智 · AI 自动化流水线设计

> **一句话：你只管每天写反思+审批产出，AI 完成从分类到生产的全流程。**

---

## 一、核心原则

| 原则 | 说明 |
|:----|:------|
| **两件事原则** | 用户只做：① 每日输入 ② 审批产出，其余全自动 |
| **文件即数据库** | 所有状态保存在 Obsidian vault 文件系统中，不引入额外数据库 |
| **AI 负责思考，脚本负责机械** | Claude API 做分类/判断/生成；Python 做调度/文件操作/API 调用 |
| **模块化生产管线** | 视频/图文/服务各自独立，可替换可扩展 |
| **反哺闭环** | 每次发布数据回写看板，系统持续进化 |

## 三、模块详细设计

### 3.1 每日输入模板

**文件位置**：`🌱 原料库/日输入/YYYY-MM-DD.md`
**格式**：

```markdown
---
created: 2026-06-21
type: daily-input
---

## 📝 今日所思所想

[自由书写区域，想到什么写什么]

## ✅ 今日待办

- [ ] 任务描述

## 💡 灵感一闪

[突然想到的选题、点子、问题]
```

**设计要点**：
- 三段式：所思所想 → 知识沉淀；待办 → 行动管理；灵感 → 选题库
- 自由书写，不需要用户提前分类
- 一天一个文件，文件名即日期

### 3.2 AI 分类引擎

**触发方式**：Watchdog 检测到 `🌱 原料库/日输入/` 有新文件 → 启动分类

**四层分类逻辑**：

| 内容类型 | AI 判断标准 | 目标目录 | 产出潜力标签 |
|---------|-----------|---------|------------|
| 价值观、信念、自我认知 | "这就是我"的陈述 | `🍎 成品区/种子/` | 无（直接入库） |
| 技能、方法、经验技巧 | "我能怎么做"的陈述 | `🍎 成品区/工具/` | 🔧 工具提炼 |
| 规则、规范、操作手册 | "应该怎么做"的陈述 | `🍎 成品区/规范/` | 无（直接入库） |
| 数据、观察、事件记录 | "发生了什么"的陈述 | 留在 `🌱 原料库/` | 📹/📝 产出判断 |
| 待办任务、项目 | "要做什么"的陈述 | `🌿 加工间/` | ❓ 待深入 |

**产出潜力标签（5种）**：

| 标签 | 含义 | 后续动作 |
|:----|:-----|---------|
| ⛔ 无产出价值 | 纯记录，归档即可 | 不触发任何生产 |
| 📹 适合做视频 | 有视觉表现力的选题 | 草拟口播脚本 |
| 📝 适合做图文 | 适合文章呈现的知识 | 生成公众号文章 |
| 🔧 适合做工具/规范 | 可提炼为可复用的认知工具 | 自动格式化后入库 |
| ❓ 待深入 | 值得探究但不明确怎么做 | 放入问题库 |

**技术实现**：
- 调用 Claude API（claude-sonnet-4-6 或更新），每次日输入文件触发一次请求
- Prompt 工程：将四层分类标准 + 5种产出标签 + 用户写的种子/工具现有库作为上下文
- 分类结果写入 `⚙️ 反哺弧/看板/分类日志.json`

### 3.3 产出规划器

AI 根据标注"有产出价值"的内容，自动生成具体的产出方案：

```
输入："今天发现水景视频的评论区很多人问过滤系统要不要做"
    ▼
AI 判断：事件层 + 📹 适合做视频
    ▼
自动生成：
  ├─ 标题建议："锦鲤池过滤系统到底要不要做？一次说清楚"
  ├─ 脚本草稿：3分钟口播稿（已有 FFmpeg 管线风格）
  ├─ 封面话术："90%的人都被坑过"
  └─ 建议平台：视频号
    ▼
写入 待审批.json  →  审批面板显示
```

对于"适合做图文"的内容，额外生成：
- 适配公众号的排版（标题分级、引用、加粗）
- 封面图建议

对于"🔧 适合做工具/规范"的内容，直接格式化后入库，**不需要审批**。

### 3.4 桌面审批面板（HTML）

**设计目标**：双击桌面快捷方式 → 浏览器打开 → 所有待审项一目了然

**技术方案**：
- 纯前端 HTML + CSS + JavaScript（零依赖，双击即开）
- 数据源：读取 `⚙️ 反哺弧/看板/待审批.json`（本地文件，同源策略通过 file:// 或本地服务器绕过）
- 用户操作：✅ 通过 / ✏️ 修改 / 🗑️ 跳过
- 审批操作写入 `⚙️ 反哺弧/看板/审批日志.json`

**UI 布局**：

```

├─────────────────────────────────────────────────────────────┤

│                                                             │
│  ┌─────────────────────────────────────────────────────────┐ │

│  │ AI分析：来自你今日所思所想→评论区高频问题                 │ │
```

**审批操作的数据流向**：
```
用户点 ✅ 通过
    │
    ├─ 📹 视频 → 待审批.json 标记 approved
    │           → 生产引擎检测到 → 调用 FFmpeg 管线
    │           → 成品输出到 桌面/视频成品/
    │           → 你在电脑上拿到视频 → 手动上传视频号
    │
    ├─ 📝 文章 → 待审批.json 标记 approved
    │           → 生产引擎检测到 → 调用公众号 API
    │           → AI 完善正文 → 写入公众号草稿箱
    │           → 你打开公众号后台 → 草稿箱 → 直接发布
    │
    └─ 🗑️ 跳过 → 待审批.json 标记 skipped
                → 不触发生产
```

### 3.5 生产执行器

**视频管线（现有）**：
- 当前：FFmpeg 口播管线，3分钟适配
- 接口：接收口播稿 → 输出成片
- 定位：模块化，可替换

**公众号文章管线（新增）**：
- 接口：[微信公众号·创建草稿 API](https://developers.weixin.qq.com/doc/offiaccount/Draft_Box/Add_draft.html)
- 流程：
  1. 获取 Access Token（定时刷新，7200s 过期）
  2. 组装文章 JSON（标题、正文HTML、封面、摘要、作者）
  3. POST 到草稿箱
  4. 写入审批日志：`已写入公众号草稿箱`
- 凭证配置在 `.env` 文件中，已添加 `.gitignore`

**未来管线扩展点**：
- 长视频管线（剪映开放平台 / AI 视频工具）
- 知识付费课程打包
- 小红书/抖音图文适配

### 3.6 反哺弧

**数据录入**：
- 你手动在审批面板或 Obsidian 中录入发布数据（播放量/点赞/关注）
- 或者未来接入各平台数据 API 后自动采集

**自动更新看板**：
- 更新 `⚙️ 反哺弧/看板/总控看板.md`
- 重新计算健康分、循环率
- 异常值自动预警（比如"连续3条视频播放低于100"）

**种子/工具库反哺**：
- 数据好的内容模式 → AI 提炼为工具/规范
- 放在"待入库"区，你审批确认后正式入库

## 五、实施阶段

### 第一阶段：核心流水线（当前→下一周）
1. 搭建引擎骨架（Watchdog + 分类引擎）
2. 实现 Claude API 四层分类 + 产出标签
3. 实现审批面板 HTML（静态版本）
4. 实现"生产执行"中 ✅ 通过后的事件响应
5. 验证完整链路：写输入 → 分类 → 审批 → 生产

### 第二阶段：公众号接入 + 审批面板完善
1. 实现 `wechat_publisher.py`（Access Token 管理 + 草稿 API）
2. 审批面板增加"已发布"状态追踪
3. 桌面快捷方式制作（.bat / exe 包装）
4. 反哺弧自动看板更新

### 第三阶段：长尾优化
1. 视频管线改进 / 替换研究
2. 平台扩展调研（知识付费、小红书等）
3. 自动化程度提升（逐步放开更多审批项）
4. AI 提炼工具/规范的自动流程

## 六、风险与限制

| 风险 | 影响 | 缓解措施 |
|:----|:-----|:---------|
| Claude API 费用 | 每次分类/生成花费 token | 按日输入频率定价可预期 |
| 微信公众号 API 限额 | 草稿创建有限频 | 缓存 Access Token，每日限额内使用 |
| 视频管线效果一般 | 产出视频质量取决于现有管线 | 管线设计为可替换模块 |
| AI 分类偏差 | 分错类导致内容放错位置 | 分类日志可追溯，用户可在审批面板修正 |
