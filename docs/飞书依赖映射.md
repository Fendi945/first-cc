# 飞书 API 依赖映射

> 用途：Engine 与飞书 API 的全部集成点一览。飞书出问题时，对照此文档排查。
> 最后更新：2026-06-27

---

## 一、认证与凭证

| 配置项 | 来源 | 用途 |
|--------|------|------|
| `FEISHU_APP_ID` | `.env` | 飞书自建应用 App ID |
| `FEISHU_APP_SECRET` | `.env` | 飞书自建应用 App Secret |
| `FEISHU_SYNC_INTERVAL` | `.env` | 同步间隔（默认 1800 秒 = 30 分钟） |

认证方式：`tenant_access_token`（内建应用），自动管理刷新与重试。

### 凭证失效时的现象
- Server 启动日志报 `飞书认证失败: ...`（code=99991663 / 99991668）
- `/api/feishu/health` 返回 `connected: false`
- 服务不中断，自动降级为本地模式（`local_mode: true`）

## 二、API 端点清单

所有端点基于 `https://open.feishu.cn/open-apis`。

### 2.1 认证

| 方法 | 路径 | 用途 |
|------|------|------|
| POST | `/auth/v3/tenant_access_token/internal` | 获取 tenant_access_token |

### 2.2 多维表格 (Bitable)

| 方法 | 路径 | 用途 |
|------|------|------|
| POST | `/bitable/v1/apps` | 创建多维表格 |
| GET | `/bitable/v1/apps/{app_token}/tables` | 列出数据表 |
| GET | `/bitable/v1/apps/{app_token}/tables/{table_id}/fields` | 列出字段定义 |
| POST | `/bitable/v1/apps/{app_token}/tables/{table_id}/fields` | 创建字段 |
| GET | `/bitable/v1/apps/{app_token}/tables/{table_id}/records` | 列出记录 |
| POST | `/bitable/v1/apps/{app_token}/tables/{table_id}/records` | 创建记录 |
| PUT | `/bitable/v1/apps/{app_token}/tables/{table_id}/records/{record_id}` | 更新记录 |

### 2.3 云空间 (Drive)

| 方法 | 路径 | 用途 |
|------|------|------|
| POST | `/drive/v1/files/create_folder` | 创建文件夹 |
| POST | `/drive/v1/files/upload_all` | 上传文件 |

### 2.4 文档 (Docx)

| 方法 | 路径 | 用途 |
|------|------|------|
| GET | `/docx/v1/documents/{document_token}/raw_content` | 获取文档原始内容 |

## 五、状态文件

| 文件 | 用途 |
|------|------|
| `feishu_bitable_state.json` | 记录已创建的多维表格 app_token、table_id、已上传文件 token |
| `feishu_kanban_state.json` | 记录看板的 app_token、table_id、本地↔飞书记录映射 |

丢失影响：丢失后会在下次同步时重新创建表格或重新建立映射，不会丢数据但可能产生重复记录。

## 六、Server 接口

定义位置：`engine/server.py`

### Feishu 相关 API

| 路径 | 方法 | 用途 | 降级行为 |
|------|------|------|---------|
| `/api/feishu/status` | GET | 同步器状态 + 健康检查 | 未初始化返回 error |
| `/api/feishu/health` | GET | 轻量健康检查（`connected` + `local_mode`） | 未初始化返回 `connected: false` |
| `/api/feishu/bitable/status` | GET | 多维表格状态 | 未初始化返回 error |
| `/api/feishu/kanban/status` | GET | 看板状态 | 未初始化返回 error |
| `/api/feishu/sync` | POST | 触发一次同步 | 失败时设 `local_mode=true`，不中断 |
| `/api/feishu/bitable/sync` | POST | 触发多维表格同步 | 同上 |
| `/api/feishu/kanban/sync` | POST | 触发看板双向同步 | 同上 |
| `/api/feishu/bitable/record` | POST | 手动录一条平台数据 | 失败时写入本地 `data_records_fallback.json` |

### 健康端点 `/api/health` 中的飞书字段

```json
{
  "ok": true,
  "feishu": "ok" | "local_mode" | "disconnected"
}
```

- `ok`：连接正常
- `local_mode`：飞书不可用，数据降级到本地存储
- `disconnected`：未连接但未降级（启动中或未初始化）

## 七、常见故障排查

### 7.1 Token 认证失败

```
飞书认证失败: ... (code=99991663)
```

**原因：** App ID 或 App Secret 错误。
**排查：** 检查 `.env` 中的 `FEISHU_APP_ID` 和 `FEISHU_APP_SECRET` 是否与飞书开发者后台一致。
**验证：** 用 curl 手动测试：
```bash
curl -X POST https://open.feishu.cn/open-apis/auth/v3/tenant_access_token/internal \
  -H "Content-Type: application/json" \
  -d '{"app_id":"...","app_secret":"..."}'
```
正常返回应包含 `"code": 0` 和 `tenant_access_token`。

### 7.2 多维表格操作失败

```
飞书 API 错误 [...]: ... (code=...)
```

**常见原因：**
- `app_token` 无效（表格被手动删除）
- `table_id` 无效（表格结构变更）
- 字段名不匹配（飞书端重命名字段后与 `BITABLE_DEFS` 不一致）

**修复：** 删除 `feishu_bitable_state.json`，重启 server。Engine 会自动重建表格。

### 7.3 看板同步冲突

```
看板同步初始化失败: ...
```

**原因：** 飞书端的看板状态与本地 `待审批.json` 不一致。
**修复：** 手动同步一次 `POST /api/feishu/kanban/sync`，Engine 会双向合并。

### 7.4 网络不通

```
飞书 API 请求失败 [...]: 重试 3 次后仍失败
```

**原因：** 网络不通或飞书服务中断。
**行为：** Engine 自动进入本地模式（`local_mode: true`），所有数据操作走本地文件。每 5 分钟自动重试恢复。

## 八、本地模式

当飞书 API 连续失败时，Engine 自动进入本地模式：

| 功能 | 本地模式行为 |
|------|------------|
| 审批看板 | 本地 `待审批.json` 正常读写，飞书同步跳过 |
| 多维表格 | 同步跳过，不中断审批流程 |
| 平台数据记录 | 写入 `engine/data/data_records_fallback.json` |
| 健康检查 | `/api/health` 返回 `feishu: "local_mode"` |
| 自动恢复 | 后台每 5 分钟尝试重连，成功后自动退出本地模式 |

退出本地模式不需要重启。恢复后，积压的 fallback 记录需要手动推送到飞书。
