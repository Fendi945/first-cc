2026-06-21 · 第 1 天

Flomo 同步 + OAuth 认证 + Obsidian 插件

💬 对话过程

开始：我说想接入 Flomo 笔记 → Claude 查了 Flomo API → 发现没有 REST API，只能走 MCP 协议

OAuth 踩坑：以为有个人 Token → 找不到 → 才发现 Flomo 只有 OAuth 授权码流程 → 注册客户端 → PKCE 认证

MCP 连接：用了 flomo_sync.py 连接 https://flomoapp.com/mcp → memo_search 一次只能搜 10 条

插件集成： Obsidian 插件加了捕获目录监控 + 确认弹窗 + 移入日输入逻辑

引擎测试：跑了一遍分类引擎——成功分类了院子那篇文章

有价值 今日收获
  • Flomo MCP OAuth 完整流程跑通（动态客户端注册 + PKCE + Token 刷新）
  • 10 条 Flomo 笔记成功同步到捕获目录
  • Obsidian 插件 Flomo 弹窗 + 捕获监控完成
  • 引擎扫描分类正常工作
问题 踩坑记录
  • Flomo 没有 REST API，只能用 MCP 协议
  • OAuth 首次注册返回 invalid_client，原因是用了伪造的 client_id
  • Python f-string 嵌套大括号报语法错误
  • memo_search 参数名猜错（query → keywords, timeRange → start_date）
  • Flomo 没有「个人 Token」设置入口
解决 处理方法
  • 改用 MCP Python SDK，走 OAuth 授权码流程
  • 实现动态客户端注册（POST /oauth/register）
  • PKCE S256 验证 + 本地回调服务器（端口 18765）
  • 通过调试工具查 Flomo inputSchema，确定正确参数名
  • Token 自动刷新机制（refresh_token）

渔樵问对推演 · 从内容选题到认准人生方向

💬 渔樵问对 · 推演全过程

🎣 樵者

用渔樵问对的方法，推演我的公众号选题、视频号主题和人设方向。

🪵 渔者

先问——你做过什么内容，做的时候什么感觉最来劲？

🎣 樵者

公众号25篇，视频号更杂——山海经、历史、园林手作、口播。都没有来劲的感觉。反而是和你推演系统、建网站让我兴奋得睡不着。

🪵 渔者

用体用分析：你之前做的事都是「用」，让你兴奋的是「体」——通过对话从无到有营造系统。选一个：造物者(A)、布道者(B)、建造者(C)、对话者(D)？

🎣 樵者

ACD。

🪵 渔者

帮别人造园是体，现在造自己的系统也是体——体完全没变。那你怕什么？

🎣 樵者

怕手艺生疏，怕别人不信任，怕赚不到钱。之前被老客户拖欠设计款，打过官司。我是自己断了一条腿。

🪵 渔者

这句「自己断了一条腿」最诚实。你不是怕做不好——是怕重蹈覆辙。你真正想要的是换一种活法：从「先干活再等别人给钱」到「我造我的园子，价值我自己说了算」。

🪵 渔者

第一个果子是什么？

🎣 樵者

我最想教人的不是AI怎么用——是教他从哪里思考，先认清楚自己，诚实地面对自己。

🪵 渔者

这就是你的第一个果子——《对话认知课》。不是AI课，是让人通过对话认识自己的脚手架。

推演成果 方向定稿
  • 人设：一个造园师的AI造系统实录——不是老师、不是专家，是在园子里干活的人，偶尔抬头说一句「你看，这一步我是这么干的」
  • 公众号：渔樵问对·对话认知系列——不用写不用编，截取精彩对话整理就是一篇
  • 视频号：「我在造什么」的过程记录——系统界面演进、对话片段
  • 第一个产品：《对话认知课》——让人通过AI对话先诚实地面对自己
关键认知 三重恐惧的本质
  • 怕手艺生疏 → 实际驾轻就熟（技术长在身上了）
  • 怕不被人信任 → 实质是怕再次被辜负
  • 怕赚不到钱 → 实质是怕新路也是先付出后拿钱的老路
  • 终极答案：互联网不会拖欠你的「内容款」——做一分，就有一分在
最终认知 渔樵问对式收尾

🪵 渔者

土壤没有肥沃贫瘠之分，只有适合种什么之分。物理土壤适合种需要慢生长、高信任、高单价的东西。互联网土壤适合种可以长长久久、不怕被辜负、每一寸根都属于自己的东西。

🎣 樵者

我的根是我的认知，我的诚实。互联网缺的就是这个。

🪵 渔者

这句话就够了。互联网不缺信息、不缺工具、不缺课——缺的就是一个诚实的人，老老实实说「我是这么问自己的」。

—— 方向不是选出来的，是走着走着，自己显现的 ——

钓鱼六件套框架 · 从工具分析到认知差定锚

💬 渔樵问对 · 推演全过程

🎣 樵者

渔樵问对中说命分——我们想在微信钓鱼（公众号+视频号），鱼竿鱼钩鱼饵齐全了吗？

🪵 渔者

六件套拆了一轮：钓竿（平台+人设）✅完整。钓线（内容生产线）✅已跑通，缺节奏。钓钩（人设钩子）✅有，标题钩子没打磨。钓饵（内容价值）⚠️需要从「秀结果」换到「拆过程」。浮漂（数据反馈）——等等，你说有数据？

🎣 樵者

我有看板v2啊——你忘了？监控视频号数据的。我刚更新了，AI分析了。

🪵 渔者

（读完数据沉默）我错了。浮漂在动——而且动得很清楚。

🪵 渔者

水景系列占84%播放——该不该做水景16k，懒人水景14k。锦鲤池劝退6.7k。宽话题远胜窄话题。

🎣 樵者

锦鲤池劝退那条——一半人说中肯，一半人骂我不懂养鱼、学艺不精。有人支持有人挖苦。

🪵 渔者

你站到了「专业人士」的位置上，就要接受「够不够专业」的审判。劝退型内容天然挑战别人的选择——同意你的人认同你，反驳你的人只能攻击你的专业能力。这不是你的问题，是站这个位置要承受的代价。

🪵 渔者

看看你的数据曲线：6/13爆到16k，之后一路跌到1k。爆款不可复制。但AI方法论不是靠爆款活着——网站每天更新，是日积月累的长尾资产。

🎣 樵者

如果AllIn AI方法论，就得放弃原来的园林专业知识普及——粉丝会不一样。

🪵 渔者

关键不是「园林还是AI」——关键是「秀肌肉还是拆过程」。你以前发的是「我做完了你看」，现在改发「我是怎么做的你看」。这个转换跟内容领域无关，跟心态有关。

🪵 渔者

你的客户是谁？

🎣 樵者

跟我一样深处迷茫，但不轻易言败，还在困惑中寻找方向、建造自己的人。我能给他们的是一张地图，一缕微光，一副我从坑里爬出来的脚手架。我叫他们攀登者，同路人。

🪵 渔者

（停顿）这句话要存档——从「我想做什么」推到「谁需要我做的东西」，逻辑是通的：你的体（从对话从无到有造系统）→ 你克服的三怕 → 你造出的渔樵问对方法论 → 谁需要这个：正在迷茫、还在造、不要答案要方法的人。

🎣 樵者

AI方法论是我亲手干出来的，我特喜欢，成本低，有认知门槛，不是谁都能做，也不是谁都能短时间复制的。

🪵 渔者

认知差——这三个字比「渔樵问对」更值钱。渔樵问对是方法，认知差是你的壁垒。这五条叠在一起就是护城河：亲手干出来的 × 喜欢的 × 成本低的 × 有认知门槛的 × 不能短时间复制的。

推演成果 定稿补全
  • 客户画像：「攀登者·同路人」——深处迷茫但不轻易言败，在困惑中找方向、建造自己的人
  • 核心壁垒：认知差——亲手干出来的 × 喜欢的 × 成本低的 × 有认知门槛的 × 不能短时间复制的
  • 视频号定位：第二战场，做引流口播（60秒讲怎么用渔樵问对推演方向）——不站「专家」位置，不接专业审判
  • 主战场：认知长内容——渔樵问对系列 + AI方法论推演记录，网站+公众号累积长尾
关键认知 数据验证
  • 视频号8条数据：水景系列占84%播放（16k+14k），但整体呈下降趋势（16k→1k）
  • 宽话题压倒性胜窄话题——「该不该做水景」16k vs 「洗手盆值一万」873
  • 「专业人士」人设要接受专业审判——锦鲤池劝退一半人骂学艺不精
  • 劝退型内容本身就会分裂评论区——不是内容好坏的问题
