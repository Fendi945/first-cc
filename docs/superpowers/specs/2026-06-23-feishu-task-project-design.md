# 飞书任务项目 — 设计文档

## 项目概述

在 Claude 和飞书之间建立双向文档交互通道，实现：
1. 将 Claude/Obsidian 中的文档存储到飞书多维表格
2. 将飞书中的内容下载到本地电脑
3. 第一步：将 Claude 配置为飞书机器人

## 目录结构

```
📁 飞书任务/
├── 📁 01-飞书机器人配置/       # 机器人创建、权限、API接入
├── 📁 02-文档交互/             # Obsidian↔飞书双向通道
│   ├── 📁 Obsidian到飞书/
│   └── 📁 飞书到本地/
├── 📁 03-多维表格设计/         # 表格结构、字段、同步逻辑
├── 📁 参考资料/                # API文档、截图、学习笔记
└── 📁 项目记录/                # 进度、备忘、决策记录
```

## 阶段规划

### 阶段一：飞书机器人配置
- 在飞书开放平台创建应用/机器人
- 配置权限、获取 API 凭证
- 建立 Claude 到飞书的通信链路

### 阶段二：文档交互
- Obsidian 文档 → 飞书多维表格（上传方向）
- 飞书内容 → 本地下载（下载方向）

### 阶段三：多维表格设计
- 定义表格结构和字段
- 设计自动同步逻辑和触发条件

## 技术方向

- 飞书开放平台 API（[https://open.feishu.cn](https://open.feishu.cn)）
- 多维表格 API（bitable）
- 文档 API（drive）
- 机器人消息推送（im）
